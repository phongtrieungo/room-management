# Synthetic demonstration data

All CSVs shipped under months/ in this repository are invented examples for three rooms. Each month has one readings.csv with room_code,electricity,water. They contain no tenant names or real readings. Room A-3 intentionally has a decreasing electricity reading to demonstrate review flags. No real historical CSV or PDF has been uploaded. Do not use these examples for billing.

Before uploading actual records, explicitly authorize the intended files and this private GitHub destination. Keep raw photos and secrets out of version control by default.
